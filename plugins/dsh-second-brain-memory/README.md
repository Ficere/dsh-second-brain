# dsh-second-brain-memory

Cordis / DSH Web plugin: machine-global **Memory** tab (List / Graph / Timeline) for [Ficere/dsh-second-brain](https://github.com/Ficere/dsh-second-brain).

Not an execution DAG — keep Trajectory / trajectory-graph for that.

```bash
dsh plugin --profile web add ./plugins/dsh-second-brain-memory
dsh web
```

See `README.zh.md` and `../../docs/global-memory.md`.
